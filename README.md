# Coin Dash — Partes 2 e 3 (corrigido)

Abra `project.godot` no Godot 4 e pressione **F5**. O jogador começa no centro, visível e à frente do fundo. Use as setas para movimentar e coletar moedas.

Correções: `new_game()` agora é chamado automaticamente; o personagem não fica oculto; Z Index do fundo -1 e do jogador 1; conexões de sinais para coleta e temporizador; animações iniciadas com `play()`.

O projeto cobre as partes 2 e 3. A interface visual (HUD) é assunto da parte 4 e não foi incluída. A pontuação é exibida no painel **Saída** do Godot.
